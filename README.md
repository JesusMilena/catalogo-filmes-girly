========================================================================
                      CATÁLOGO DE FILMES GIRLY
========================================================================

Uma aplicação web interativa e responsiva para navegar por catálogos 
cinematográficos e gerenciar seus filmes favoritos.

🔗 Link do Projeto: https://github.com/JesusMilena/catalogo-filmes-girly
🔗 Site Publicado: https://jesusmilena.github.io/catalogo-filmes-girly/

------------------------------------------------------------------------
1. TECNOLOGIAS UTILIZADAS
------------------------------------------------------------------------
* Front-End: HTML5 / CSS3 / JavaScript (ES6+)
* API Externa: The Movie Database (TMDb) API (https://www.themoviedb.org/)
* Banco de Dados: Firebase / Cloud Firestore (NoSQL)
* Design & Layout: CSS Grid e Flexbox (Layout Totalmente Responsivo)

------------------------------------------------------------------------
2. FUNCIONALIDADES IMPLEMENTADAS
------------------------------------------------------------------------
[X] Consulta à API da TMDb: Listagem dinâmica dos filmes mais populares, 
    renderização de pôsteres, notas e sinopses em tempo real.
[X] Barra de Pesquisa: Filtragem assíncrona de títulos diretamente pelos 
    endpoints de busca oficiais da API.
[X] Armazenamento no Banco de Dados: Sistema interativo que permite 
    favoritar títulos, salvando o ID do filme atrelado ao usuário diretamente 
    no Cloud Firestore.
[X] Persistência de Estado: Recuperação reativa dos favoritos salvos 
    no banco de dados imediatamente ao recarregar a plataforma.
[X] Interface Responsiva: Layout moderno adaptado e otimizado para 
    dispositivos móveis, tablets e computadores.

------------------------------------------------------------------------
3. COMO EXECUTAR O PROJETO LOCALMENTE
------------------------------------------------------------------------
Passo 1: Certifique-se de ter o Git instalado em sua máquina.
Passo 2: Abra o terminal e clone este repositório com o comando:
         git clone https://github.com/JesusMilena/catalogo-filmes-girly.git

Passo 3: Acesse a pasta do projeto através do terminal:
         cd catalogo-filmes-girly

Passo 4: Abra o arquivo 'index.html' diretamente em seu navegador de 
         preferência ou utilize a extensão Live Server do VS Code.
